# Доказательство локальной обработки для жюри

Эта копия оценивает транскрипт через Ollama на том же компьютере.

## Что показать

1. Запустить `npm run local:check`. Команда выводит локальный адрес Ollama и установленную модель.
2. Открыть `http://127.0.0.1:8080/api/model`. Ответ содержит:
   - `provider: "ollama-local"`;
   - `base: "http://127.0.0.1:11434"`;
   - `local_only: true`;
   - `transcript_leaves_device: false`.
3. Отключить интернет и оценить заранее загруженный диалог. Оценка продолжит работать.
4. Показать `server/lib/llm.js`: внешний адрес модели отклоняется до вызова `fetch`, а запрос идёт только на `/api/chat` локальной Ollama.

## Граница гарантии

- Транскрипт, промпт и ответ модели остаются на компьютере.
- Результаты хранятся в локальном каталоге `data/`.
- Сервер интерфейса слушает только `127.0.0.1`.
- Если настроен `CQA_API_URL`, приложение может получить исходный набор у организаторов. Оно не отправляет туда результат оценки или промпт.
- Для полностью автономной демонстрации сначала загрузите или импортируйте набор, затем отключите интернет.
